# Indépendant manutention — le parcours réel

État : généré
Dernière revue : 2026-09-24

> Être trouvé, planifié, prouvé, payé — sans relancer personne.

## Les étapes, dans l'ordre

1. **On sait quand vous êtes libre** — Vous posez vos disponibilités et vos tarifs une fois. Les donneurs d'ordre voient les créneaux réels, pas une promesse.
   · Écran : Ma disponibilité · Module : planning
2. **Une mission vous arrive** — Date, adresse, durée prévue, ce qu'il y a à faire, qui commande. Vous acceptez ou vous refusez — en un geste, pas en trois appels.
   · Écran : Mes missions · Module : planning
3. **Vous pointez sur place** — Arrivée, départ, pauses. C'est ce compteur qui se facturera, pas une estimation reconstituée le lendemain.
   · Écran : Terrain · Module : terrain
4. **Vous repartez avec la preuve** — Photos de l'état des biens, réserves éventuelles, signature du client sur votre téléphone. Le litige devient un document.
   · Écran : Rapport d'intervention · Module : rapport_chantier
5. **La facture sort des heures acceptées** — Les heures validées deviennent la facture, numérotée et conforme. Vous ne recomptez rien.
   · Écran : Ma facturation · Module : facturation
6. **Vous voyez ce qui reste dû** — Qui a payé, qui doit encore, depuis combien de jours. La relance part d'ici.
   · Écran : Mes encours · Module : facturation

## Ce que cette offre ne fait PAS

- Le relevé de volume et le devis de déménagement : ce n'est pas votre métier.
- La paie : vous êtes indépendant, il n'y a personne à payer.
- Un seul accès — l'offre est faite pour une personne, pas pour une équipe.
- Le numéro d'entreprise est vérifié à l'inscription : sans BCE valide, pas de compte.
