# Donneur d'ordre — le parcours réel

État : généré
Dernière revue : 2026-09-23

> Envoyer une mission, la suivre, en garder la preuve.

## Les étapes, dans l'ordre

1. **Vous confiez une mission** — Ce qu'il y a à faire, où, quand, pour quel client. Une fois, au bon endroit.
   · Écran : Nouvelle mission · Module : —
2. **Un prestataire l'accepte** — Vous voyez qui prend, et quand. Plus d'appels pour savoir si c'est couvert.
   · Écran : Suivi des missions · Module : —
3. **Vous suivez sans téléphoner** — Heure d'arrivée réelle, qui est intervenu, où ça en est.
   · Écran : Suivi des missions · Module : —
4. **La livraison est prouvée** — Signature du destinataire, photos de l'état des biens. Le litige se traite avec un document.
   · Écran : Preuves · Module : —

## Ce que cette offre ne fait PAS

- La gestion de votre propre flotte et de vos propres équipes : c'est une offre déménageur.
- Gratuit à l'usage, mais une commission s'applique aux missions confiées via le réseau.
