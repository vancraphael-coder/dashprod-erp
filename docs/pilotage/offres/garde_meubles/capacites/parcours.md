# Garde-meubles — le parcours réel

État : généré
Dernière revue : 2026-09-24

> Vos contrats se facturent chaque mois, sans y penser.

## Les étapes, dans l'ordre

1. **Un client réserve un box** — Unité attribuée, durée, tarif. Le contrat existe, daté.
   · Écran : Contrats · Module : —
2. **L'échéance tombe toute seule** — Chaque période génère sa facture, avec le prorata d'entrée et de sortie calculé.
   · Écran : Échéances · Module : —
3. **Vous voyez ce qui est occupé** — Quel box, par qui, jusqu'à quand. Sur un plan.
   · Écran : Stockage · Module : —
4. **Vous suivez les impayés** — Référence de paiement, ce qui reste dû, depuis quand.
   · Écran : Encours · Module : —

## Ce que cette offre ne fait PAS

- Le déménagement lui-même : si vous transportez aussi, c'est une offre déménageur.
