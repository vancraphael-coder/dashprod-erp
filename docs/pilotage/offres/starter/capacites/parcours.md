# Basique — le parcours réel

État : généré
Dernière revue : 2026-09-23

> Sortir du papier sans changer de métier.

## Les étapes, dans l'ordre

1. **Un particulier appelle** — Vous notez qui, quoi, où, quand — une fois. Ça ne se ressaisit plus nulle part ensuite.
   · Écran : Carnet · Module : crm
2. **Vous allez voir sur place** — Pièce par pièce, le volume se calcule pendant que vous marchez. Plus de mètres cubes estimés au doigt mouillé.
   · Écran : Relevé · Module : releve
3. **Le devis part le soir même** — Les volumes relevés deviennent un prix. Vos tarifs, votre papier à en-tête, aucun calcul refait à la main.
   · Écran : Devis · Module : devis
4. **Le client signe en ligne** — Un lien, une signature, une trace horodatée. Pas d'imprimante, pas de scan, pas de « je n'ai jamais reçu ».
   · Écran : Offre · Module : signature_client
5. **Le jour J, l'équipe sait** — Le planning est sur le téléphone des déménageurs, avec l'adresse, l'accès, le matériel. Vous n'appelez plus pour expliquer.
   · Écran : Planning et Terrain · Module : planning
6. **La facture suit le chantier** — Ce qui a été fait devient la facture, numérotée dans une séquence continue. Rien à recopier.
   · Écran : Facture · Module : facturation

## Ce que cette offre ne fait PAS

- La facturation électronique vers les entreprises (Peppol) — c'est Regular.
- L'export comptable sans ressaisie — c'est Regular.
- La paie et les heures d'équipe — c'est Regular.
- Plusieurs centres logistiques — c'est Pro.
